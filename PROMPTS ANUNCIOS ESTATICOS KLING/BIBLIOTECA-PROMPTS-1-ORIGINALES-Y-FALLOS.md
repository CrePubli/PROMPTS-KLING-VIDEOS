# ❌ SECCIÓN B — FALLOS (no funcionaron) + por qué + corrección

## ❌ B1 — Linaje Guerrero (poster con FUEGO + mano que lo mece)
**Por qué falló:** se animó el fuego del poster + desapareció la cajita de texto. CAUSA: el prompt
PEDÍA mover el poster (sway/swing) Y a la vez prohibía animar el fuego → contradicción → el
movimiento se contagió al fuego. La cajita de texto se solapaba con la mano/poster en movimiento.
**Corrección (lo que SÍ funciona):** CONGELAR el poster por completo (sin sway, la mano no lo mueve),
movimiento solo de cámara + ambiente de sala (luces, polvo), y la cajita de texto como "fixed screen
overlay on top, never occluded by the hand or poster". Ver receta en MODELO-KLING.md (FALLO #1).

## ❌ B2 — Visión sin límites (gafas, efecto MÁQUINA DE ESCRIBIR)
**Por qué falló:** el texto pequeño se "escribía y borraba" (typewriter). CAUSA: (1) el texto ya
estaba ROTO en la imagen base (IA), (2) se animaron 5 zonas a la vez, (3) citar el texto roto lo
empeoró.
**Corrección:** texto = "frozen flat pixel layer, do NOT read/re-render/redraw" (sin citar las
palabras rotas) + animar UNA sola zona aislada + negativo "no typewriter text effect". (FALLO #2)

## ❌ B3 — Velocidad (misma imagen del A7, prompts que la rompían)
**Por qué falló:** animó el texto. CAUSA: estos prompts animaban el FONDO DE MONTAÑAS de la mitad
inferior, justo donde están las etiquetas pequeñas → el movimiento se contagió al texto. El A7
funcionó porque animaba SOLO al hombre (zona aislada).
**Corrección:** animar solo el hombre (arriba, aislado) + CONGELAR toda la mitad inferior (montañas +
productos + etiquetas) + texto como píxeles + cero cámara. (FALLO #3)

## ❌ B4 — Póster personalizado / tracklist (texto DIMINUTO)
**Por qué falló:** 5 prompts probados (varios casi perfectos) y Kling 3.0 SEGUÍA inventando texto.
CAUSA: el poster tiene un tracklist de letra microscópica imposible de preservar para 3.0.
**Corrección:** **cambiar a Kling 2.6** (más fiel, preserva texto diminuto) + cámara clavada + 1
sujeto + texto como píxeles. El prompt era correcto; el lever era el MODELO. (FALLO #4)

## ❌ B5 — Tu foto hecha póster (callouts rotos + pull-back rompe el texto)
**Por qué falló:** texto cambiado, "cuando se alejaba le puso una cosa rara". CAUSA: (1) callouts con
texto roto en origen, (2) el PULL-BACK de cámara re-renderiza el cuadro y degrada el texto pequeño.
**Corrección:** CERO movimiento de cámara (con texto pequeño, mover cámara = veneno) + no animar las
líneas de callout + texto como píxeles. (FALLO #5)

## ❌ B6 — El fútbol se vive en grande (colección: BANDERAS animadas + texto roto)
**Por qué falló:** se animaron las banderas impresas + texto de abajo roto. CAUSA: (1) las BANDERAS
son el imán de movimiento más fuerte; al dar permiso de animar algo (embers), el movimiento se
contagió a ellas; (2) los embers subían desde abajo, sobre el texto.
**Corrección (la que funcionó):** motion sink ARRIBA (luces/embers en zona superior) + franja inferior
FROZEN UI BAR (iconos nombrados) + clip corto ~5s + flags/caras "frozen ink". (FALLO #6)
